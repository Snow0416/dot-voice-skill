# Dot Voice Skill

**状态：尚未实现。此仓库目前没有可安装、可用的变声插件。**

目标是在 ChatGPT dot 的原生通话中扩充可选声线，并支持用户自定义声音。

截至 2026-10-10，在查阅的公开文档和当前可用能力中，尚未找到受支持的 dot 原生声线修改接口。通用 ChatGPT Voice 的声音选择不能证明会影响 dot 通话。当前无法验证或交付这一功能，因此没有发布替代实现。

## 范围

本项目只针对 dot 原生通话声音。独立 TTS 播放、语气提示词、普通 Voice 设置指南均不作为目标功能的实现。

## English
